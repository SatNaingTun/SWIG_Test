# SWIG Java Compilation & Integration Guide

This guide details the end-to-end process for using SWIG to wrap C code for **Java** on Linux, including setting up `JAVA_HOME` and compiling JNI dynamic shared libraries.

## Step 1: Prepare the C Source and Header Files

Ensure your C code and declarations are prepared.

**`example.h`**

```
#ifndef EXAMPLE_H
#define EXAMPLE_H

extern double My_variable;
int fact(int n);
int my_mod(int x, int y);

#endif

```

**`example.c`**

```
#include "example.h"

double My_variable = 3.0;

int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

int my_mod(int x, int y) {
    return x % y;
}

```

## Step 2: Create the SWIG Interface File (`example.i`)

Create an interface file specifying the C declarations to copy into the wrapper (`%{%}`) and the functions to bind for Java.

**`example.i`**

```
%module example

%{
/* Included directly in example_wrap.c */
extern double My_variable;
extern int fact(int n);
extern int my_mod(int x, int y);
%}

/* Declarations parsed by SWIG for Java wrapper creation */
extern double My_variable;
extern int fact(int n);
extern int my_mod(int x, int y);

```

## Step 3: Generate Java Wrappers and C Wrapper Code

Run SWIG with the `-java` flag:

```
swig -java example.i

```

This generates:

* `example_wrap.c` (C wrapper code containing JNI functions)

* `example.java` (High-level Java interface class)

* `exampleJNI.java` (Low-level JNI proxy bindings)

## Step 4: Configure `JAVA_HOME` and Install JDK Headers

To compile `example_wrap.c`, GCC needs `jni.h`. Make sure the JDK development package is installed and `JAVA_HOME` is set.

1. **Install JDK Development Package (if missing):**

   ```
   sudo apt update
   sudo apt install openjdk-25-jdk
   
   ```

2. **Export `JAVA_HOME` in your current terminal session:**

   ```
   export JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64
   
   ```

3. **Verify `jni.h` exists:**

   ```
   ls $JAVA_HOME/include/jni.h
   
   ```

   *(It must display `/usr/lib/jvm/java-25-openjdk-amd64/include/jni.h`)*

## Step 5: Compile Object Files and Build Shared Library

1. **Compile C source and wrapper into object files (`.o`):**

   ```
   gcc -c -fPIC example.c example_wrap.c -I"$JAVA_HOME/include" -I"$JAVA_HOME/include/linux"
   
   ```

2. **Link into a shared object file (`libexample.so`):**
   *(Note: Linux requires the `lib` prefix so Java can find it with `System.loadLibrary("example")`).*

   ```
   gcc -shared example.o example_wrap.o -o libexample.so
   
   ```

## Step 6: Create and Run the Java Driver Application

1. **Create `Main.java`:**

   ```
   public class Main {
       static {
           // Loads libexample.so from the Java library path
           System.loadLibrary("example");
       }
   
       public static void main(String[] args) {
           // Test functions
           System.out.println("fact(4) = " + example.fact(4));
           System.out.println("my_mod(23, 7) = " + example.my_mod(23, 7));
   
           // Test global variable accessors generated by SWIG
           example.setMy_variable(3.0);
           double result = example.getMy_variable() + 4.5;
           System.out.println("My_variable + 4.5 = " + result);
       }
   }
   
   ```

2. **Compile Java sources:**

   ```
   javac *.java
   
   ```

3. **Run the Java application:**
   *(Use `-Djava.library.path=.` to specify the current directory for the native library)*

   ```
   java -Djava.library.path=. Main
   
   ```

### Expected Output

```
fact(4) = 24
my_mod(23, 7) = 2
My_variable + 4.5 = 7.5

```
