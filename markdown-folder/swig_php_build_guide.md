# SWIG PHP Compilation & Integration Guide

This guide details the step-by-step process for using SWIG to wrap C code for **PHP** on Linux.

## Step 1: Prepare the C Source and Header Files

Ensure your C code and declarations are prepared.

**`example.h`**

```c
#ifndef EXAMPLE_H
#define EXAMPLE_H

extern double My_variable;
int fact(int n);
int my_mod(int x, int y);

#endif
```

**`example.c`**

```c
#include "example.h"

double My_variable = 3.0;

int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

int my_mod(int x, int y) {
    return x % y;
}
```

## Step 2: Create the SWIG Interface File (`example.i`)

Create an interface file specifying the C declarations to include in the wrapper block (`%{ ... %}`) and the functions to expose to PHP.

**`example.i`**

```swig
%module example

%{
#include "example.h"
extern double My_variable;
extern int fact(int n);
extern int my_mod(int x, int y);
%}

/* Declarations parsed by SWIG to generate PHP wrappers */
extern double My_variable;
extern int fact(int n);
extern int my_mod(int x, int y);
```

## Step 3: Generate PHP Wrapper Files

Run SWIG using the `-php` flag:

```bash
swig -php example.i
```

This generates:
* **`example_wrap.c`**: The C wrapper code interfacing with PHP's Zend Engine API.
* **`php_example.h`**: Header file containing PHP extension declarations.
* **`example.php`**: The script containing high-level PHP bindings (if generated by your SWIG version).

## Step 4: Compile Object Files and Link Shared Library

1. **Compile C source and wrapper into object files (`.o`):**

   Use `php-config --includes` to auto-detect system PHP header paths.

   ```bash
   gcc -c -fPIC example.c example_wrap.c $(php-config --includes)
   ```

2. **Link into a PHP dynamic module (`example.so`):**

   ```bash
   gcc -shared example.o example_wrap.o -o example.so
   ```

## Step 5: Create and Run the PHP Test Script

1. Create a PHP script named `test.php`:

   **`test.php`**

   ```php
   <?php
   // Include generated PHP wrapper module if present
   if (file_exists('example.php')) {
       include('example.php');
   }

   // Call wrapped C functions
   echo "fact(4) = " . fact(4) . "\n";
   echo "my_mod(23, 7) = " . my_mod(23, 7) . "\n";

   // Read and modify global variables via SWIG getter/setter functions
   if (function_exists('My_variable_set')) {
       My_variable_set(3.0);
       $result = My_variable_get() + 4.5;
       echo "My_variable + 4.5 = " . $result . "\n";
   }
   ?>
   ```

2. Execute the test script loading the compiled extension:

   ```bash
   php -d extension=./example.so test.php
   ```

### Expected Output

```text
fact(4) = 24
my_mod(23, 7) = 2
My_variable + 4.5 = 7.5
```
